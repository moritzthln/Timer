# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub instead:
[Report a vulnerability](https://github.com/moritzthln/Timer/security/advisories/new).

You will get an answer within a few days. Once a fix is released, the report
is published with credit to you, unless you prefer otherwise.

## Scope

Timer runs locally, makes no network requests and stores data only in your
user account. Relevant reports include, for example, a way for the app's
Accessibility or Automation access to be abused by another process, or data
written somewhere other than documented in the README.
